# RECF Achieve Pinnacle (REC Foundation, 2026 to 2027)

Generality test (spec section 6.11): the same pins and cups as Override with different scoring,
so it changes mostly the objective.
[Game manual](https://recf.org/documents/2026/06/game-manual-recf-achieve-pinnacle.pdf/).

Scene files (`scene.yaml`, `scoring.py`, `strategy_code.yaml`, `landmarks.yaml`,
`robot_limits.yaml`) are not written yet. See `docs/scene_authoring.md`.
